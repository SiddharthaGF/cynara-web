# API client (`src/api/generated`)

The frontend calls `cynara-api` through a typed client generated by
`@hey-api/openapi-ts` from the API's committed OpenAPI contract
(`contracts/openapi.json` in the `cynara-api` repository). The generated files
live in `src/api/generated/`, are committed, and are covered by a CI drift gate.

## Rules

- **Never hand-edit `src/api/generated/**`.** Regenerate instead. The directory
  is ignored by `oxfmt`, `oxlint`, and the pre-commit hook; a manual edit is
  lost on the next `pnpm api:generate`.
- The generator runs in isolation under `tools/api-client` (its own workspace
  package with a pinned TypeScript version) so it cannot clash with the app's
  TypeScript 7 toolchain.
- Runtime integration — tenant/actor headers, `ApiError` mapping, network
  classification, cancellation — lives in `src/api/client-runtime.ts` (wired via
  `runtimeConfigPath`). The façades in `src/api/*.ts` are the only app code that
  calls the SDK; components and hooks never call it directly.

## Regeneration procedure

1. Make sure the `cynara-api` checkout sits next to `cynara-web` (default source
   `../cynara-api/contracts/openapi.json`), or point `OPENAPI_SPEC` /
   `OPENAPI_SPEC_URL` at another contract.
2. `pnpm api:generate`
3. Review the diff under `src/api/generated/`.
4. Run `pnpm typecheck && pnpm lint:check && pnpm test`. A contract that gained
   fields can surface new type errors in the façades or their consumers —
   resolve them in the same change.
5. Commit the regenerated output together with the contract change that
   motivated it.

`pnpm api:check` regenerates and exits non-zero when the committed output is
stale. The `API client drift` workflow runs it in CI.

## Editing the contract

- **Adding a field** — add it to the JSON:API schema in `cynara-api`, commit,
  and regenerate. Generated DTO properties come out optional (`field?: T`); the
  façades promote them to required with `requireDto` because the API always
  serializes complete records.
- **Adding an endpoint** — give the operation an `operationId` in the contract
  so the SDK function gets a readable name; otherwise `openapi-ts` derives one
  from the method + path (see the `POST /api/formVersions/{id}/publish`-style
  operations tracked under CYN-55).
- **Known contract gaps** — several mutation endpoints declare no `requestBody`
  schema, so the generated SDK types the body as `body?: never`. The façades
  build the JSON:API document and cast at the call site (marked `CYN-55` in the
  code). Add the request body schemas to the contract to remove those casts.

## Pinning the API ref for CI

`.github/workflows/api-client.yml` regenerates against a pinned ref of
`cynara-api`:

- The workflow's `API_CONTRACT_REF` defaults to a pinned SHA of `cynara-api`
  (`baace8bdf20c20f75677f6b519e388d5cd60cd90` — the `main` HEAD whose contract
  the committed output was generated against).
- Before depending on a contract change, pin the workflow to the known-good SHA
  and regenerate + commit the output in the same change, so the drift gate
  compares like-for-like.
- Manual runs can override the ref via the `contract-ref` input on
  `workflow_dispatch`.

A stale pin is not itself an error — the drift gate only compares the generated
output against the pinned contract. Advance the pin deliberately.

## Upgrading the generator

`tools/api-client` pins `@hey-api/openapi-ts` and its own `typescript`:

1. Bump `@hey-api/openapi-ts` in `tools/api-client/package.json`, keeping the
   TypeScript version inside the plugin's supported peer range.
2. `pnpm install && pnpm api:generate`.
3. Review the diff — generated output can change substantially across plugin
   majors.
4. Run the full validation suite and commit the generator bump together with the
   regenerated output.

## Adding client-level tests

Vitest tests live in `src/api/__tests__/` and cover the transport adapter
(header injection, error mapping, network classification) plus one SDK smoke
test per façade (query/header construction, envelope mapping). Do not write
tests for the generated code itself — the drift gate covers it. Run with
`pnpm test`.
